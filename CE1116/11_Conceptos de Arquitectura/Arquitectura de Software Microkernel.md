## 📚 Idea/Concepto 
 
Se refiere al grado en que los elementos de un módulo están relacionados entre sí y trabajan juntos para un único objetivo el cual es la Alta Cohesión, que es el estándar deseable para la estructuración de módulos en ingeniería el cual está vinculado con la separación de responsabilidades (SoC), la Alta Cohesión es el mecanismo principal para reducir la amplificación del cambio y aislar modificaciones, lo cual directamente facilita el Bajo Acoplamiento.
