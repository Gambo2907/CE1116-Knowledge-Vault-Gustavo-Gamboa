## 📚 Idea/Concepto 
 Es un modelo de diseño de software que divide un sistema en capas horizontales, cada una con responsabilidades específicas y que se comunican entre sí de forma jerárquica. Esta división busca la Separación de Responsabilidades (SoC) y el Bajo Acoplamiento los cuales son beneficiosos para diferentes atributos como la testabilidad o la escalabilidad, específicamente el bajo acoplamiento necesita de una obligatoriedad de definir interfaces y abstracciones claras entre las capas. La comunicación jerárquica se controla por medio de reglas de interacción como el uso de interacción estricta o suelta y restricciones del flujo top-down.
