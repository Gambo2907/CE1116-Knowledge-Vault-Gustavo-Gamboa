## 📚 Idea/Concepto 
 Es el proceso de dividir texto en unidades más pequeñas llamadas tokens, que pueden ser palabras, partes de palabras (subpalabras) o caracteres, para que un modelo de inteligencia artificial pueda procesar y entender el lenguaje humano de manera matemática y estructurada. El token posee un token id que se utiliza directamente como índice para recuperar el embedding (representación vectorial) del token en una tabla de búsqueda aprendida; la tokenización busca un equilibrio entre un vocabulario manejable y la capacidad de representar eficientemente palabras raras o desconocidas mediante subpalabras. Tras la tokenización, se utilizan algoritmos específicos como Byte-Pair Encoding (BPE) o WordPiece para gestionar eficientemente el vocabulario y las palabras fuera de este.
